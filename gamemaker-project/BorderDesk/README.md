# BorderDesk GameMaker Project

이 폴더는 **GameMaker Studio 2.3+에서 바로 열 수 있는 프로젝트 스켈레톤**입니다.

## 열기
1. GameMaker 실행
2. `BorderDesk.yyp` 열기
3. Room `rm_main` 실행

## 포함 리소스
- Scripts: `scr_border_data_init`, `scr_border_flow`
- Object: `obj_border_controller` (Create/Step/Draw GUI)
- Room: `rm_main` (컨트롤러 인스턴스 포함)

## 조작
- `A`: 승인
- `D`: 거부
- `R`: 리셋
