# Border Desk Prototype

`Papers, Please` 느낌을 참고한 **미니 국경 심사 게임 틀**입니다.

## 제공 버전

- 웹 프로토타입: `index.html`, `styles.css`, `script.js`
- GameMaker 복붙 스캐폴드: `gamemaker/`
- GameMaker 바로 열기 프로젝트: `gamemaker-project/BorderDesk/BorderDesk.yyp`

## 웹 실행 방법

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## GameMaker 실행 방법

GameMaker Studio 2.3+에서 아래 프로젝트 파일을 열면 됩니다.

- `gamemaker-project/BorderDesk/BorderDesk.yyp`

자세한 내용은 `gamemaker/README_GAMEMAKER.md` 참고.
